# Security reporting

Do not disclose exploitable vulnerabilities, credentials, tokens, or personal calendar data in public issues or pull requests.

Use GitHub's private vulnerability reporting for this repository if the maintainer has enabled it. Otherwise, contact the maintainer through their GitHub profile to arrange a private reporting channel. Include affected versions, reproduction steps using synthetic data, and the expected impact. Do not send live credentials.

For protection boundaries and shipping requirements, read [security and shipping details](docs/SECURITY-AND-SHIPPING.md).

The currently maintained source version is 1.0.1. No security certification, response-time commitment, or guarantee against malware running as the logged-in OS user is implied.
