# Sharing MISO

MISO's public repository is [miso-desktop-pet](https://github.com/itsmeabirmohanta/miso-desktop-pet). The app itself remains **MISO — Your Little Butler**.

The official product website is **[miso.abirmahanta.in](https://miso.abirmahanta.in/)**. GitHub's About homepage points to it; releases remain available directly from GitHub.

## Links to share

- [Download the latest Windows installer](https://github.com/itsmeabirmohanta/miso-desktop-pet/releases/latest/download/MISO-Setup.exe)
- [Release notes, checksum, and installation guide](https://github.com/itsmeabirmohanta/miso-desktop-pet/releases/latest)
- [Product overview and source](https://github.com/itsmeabirmohanta/miso-desktop-pet)
- [Questions and ideas](https://github.com/itsmeabirmohanta/miso-desktop-pet/discussions)

The latest-download link follows the latest published release as long as its installer asset remains named `MISO-Setup.exe`. Existing links using the old `miso` repository name redirect to the renamed repository. Do not create a new repository at that old name, as doing so would replace those redirects.

## A short introduction

> Meet MISO — Your Little Butler: a desktop cat that keeps Google Calendar meetings, tasks, reminders, and important dates close by. Connect multiple accounts, add reminders through quick popups, and move your companion anywhere on screen. AI is optional. Available for Windows x64.

Pair the introduction with the public download link and the supplied banner. Use screenshots with synthetic events, never personal calendar information, account emails, tokens, or keys. Explain the current Google verification and unsigned-installer status when sharing installation instructions; those are documented in the user guide.

## Social preview image

GitHub's social-preview image is configured separately from the README banner. In **Settings → General → Social preview → Edit**, upload `src/assets/Miso-github-banner.jpg`. Its identifying export metadata has been removed. GitHub recommends a 1280 × 640 image; the supplied 1280 × 320 banner meets the minimum dimensions but link previews can crop or frame it differently.

## Maintaining discovery information

- Keep the About description and relevant topics aligned with the application's actual features. Keep the official website and the latest release's download links current.
- Add concise release notes when publishing new versions, with the supported platform and known setup requirements.
- Use Discussions for questions and ideas, issue forms for reproducible bugs and feature requests, and private reporting for security problems.
- Watch releases for updates, save the repository with a star, or share it with people who would find a desktop calendar companion useful.

Repository metadata helps people find and understand the project. Adoption also depends on reliable setup, a useful demo, and continued maintenance; these changes do not guarantee GitHub Trending placement or download growth.
