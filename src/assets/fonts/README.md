# MISO typography

MISO bundles these variable fonts locally. The interface never requests fonts from a remote service.

- **Baloo 2**: headings and the mascot's quick-entry prompts, weights 400–800. [Official Google Fonts source](https://github.com/google/fonts/tree/main/ofl/baloo2).
- **Inter**: controls, descriptions, event details and settings, weights 100–900. [Official Google Fonts source](https://github.com/google/fonts/tree/main/ofl/inter).

Each font is distributed under its included SIL Open Font License (`Baloo2-OFL.txt` and `Inter-OFL.txt`). Both licenses ship with the application. Fonts were downloaded from the linked repositories on 2026-10-09; standard system sans-serif fonts remain available as fallbacks.
